## فارسی

### 📱 درباره چقد

**چقد (Cheghad)** یک اپلیکیشن مدرن، سبک و اوپن‌سورس برای مشاهده و بررسی نرخ لحظه‌ای ارزها و اطلاعات مالی است.

چقد با استفاده از جدیدترین رویکردهای توسعه اندروید و رابط کاربری **Material 3 Expressive** ساخته شده و تمرکز آن روی **سرعت، سادگی، تجربه کاربری روان و دسترسی سریع به اطلاعات** است.

این پروژه با **Kotlin** و **Jetpack Compose** توسعه داده شده و از معماری Offline-First برای ارائه تجربه‌ای سریع و قابل‌اعتماد استفاده می‌کند.

---

### ✨ ویژگی‌ها

- 🎨 **رابط کاربری مدرن**

  * طراحی شده با Material 3 Expressive
  * پشتیبانی از حالت روشن و تاریک
  * طراحی سازگار با اندازه‌های مختلف صفحه‌نمایش

- ⚡ **کار کردن به صورت آفلاین**

  * ذخیره اطلاعات به‌صورت محلی
  * استفاده از Room Database
  * دسترسی سریع به اطلاعات ذخیره‌شده حتی بدون اینترنت

- 🔄 **همگام‌سازی هوشمند**

  * دریافت اطلاعات جدید از API
  * بروزرسانی داده‌ها با Retrofit
  * استفاده از Kotlin Coroutines برای عملیات غیرهمزمان

- 🔔 **هشدارها و یادآورها**

  * امکان تعریف هشدارهای مالی
  * یادآوری برای پیگیری قیمت‌ها و اطلاعات موردنظر

- 🚀 **سبک و سریع**

  * تمرکز روی عملکرد و مصرف بهینه منابع
  * رابط کاربری روان با Jetpack Compose

- 🔓 **اوپن سورس**

  * کد منبع عمومی
  * توسعه و مشارکت آزاد در پروژه

## English

### 📱 About Cheghad

**Cheghad** is a modern, lightweight, and open-source Android application for monitoring real-time currency exchange rates and financial information.

Built with modern Android development practices and **Material 3 Expressive**, Cheghad focuses on **speed, simplicity, performance, and a smooth user experience**.

The application is developed using **Kotlin** and **Jetpack Compose**, with an Offline-First approach for fast and reliable access to locally stored data.

---

### ✨ Features

* 🎨 **Modern UI**

  * Built with Material 3 Expressive
  * Light and Dark theme support
  * Responsive design

* ⚡ **Offline-First**

  * Local data persistence
  * Powered by Room Database
  * Fast access to cached data without an internet connection

* 🔄 **Smart Synchronization**

  * Fetches the latest data from APIs
  * Network communication powered by Retrofit
  * Asynchronous operations with Kotlin Coroutines

* 🔔 **Alerts & Reminders**

  * Custom financial alerts
  * Reminders for tracking prices and financial information

* 🚀 **Fast & Lightweight**

  * Performance-focused architecture
  * Smooth Jetpack Compose UI
  * Optimized resource usage

* 🔓 **Open Source**

  * Public source code
  * Open to contributions and improvements

---

### 🛠️ Tech Stack

| Technology                | Purpose                      |
| ------------------------- | ---------------------------- |
| **Kotlin**                | Primary programming language |
| **Jetpack Compose**       | UI development               |
| **Material 3 Expressive** | UI design system             |
| **Room**                  | Local database               |
| **Retrofit**              | API networking               |
| **Kotlin Coroutines**     | Asynchronous operations      |
| **Gradle**                | Build system                 |
